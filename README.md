# Vivi Agent

Плагин Figma, который генерирует и редактирует дизайн по текстовому описанию —
работает как агент: думает, может запросить визуальный просмотр блоков,
собирает ноды, проверяет результат и исправляет. Модель выбирается в UI
плагина; запросы идут через локальный сервер-мост в ACP-провайдеры:

- **Claude** — через мост `server/bridges/claude`
  (JSON-RPC поверх stdio, внутри `@anthropic-ai/claude-agent-sdk`).
- **Devin** (`devin:*`) — через `devin.exe acp` (настоящий ACP:
  `initialize` → `authenticate`
  → `session/new(mode:"ask")` → `session/set_config_option(model)` → `session/prompt`).

## Архитектура

```
plugin/ui (iframe) ──WebSocket──> server/ ──stdio JSON-RPC──> ACP ──> Claude | Devin
       │ postMessage
       v
plugin/code.ts ──> figma API (frame/text/rect/ellipse/line/image-ноды)
```

- `server/` — локальный мост (порт 8787): принимает запрос от плагина, держит
  ACP-сессию с выбранной моделью, стримит ответ, извлекает JSON-спеку дизайна.
- `plugin/` — плагин Figma: UI с полем модели и промпта + код, строящий ноды
  по спеке (auto-layout, цвета, шрифты, тени, скругления).

## Запуск

```bash
# 1. Сервер-мост
cd server
npm install
npm start          # ws://localhost:8787

# 2. Сборка плагина
cd plugin
npm install
npm run build      # -> plugin/dist/{code.js, ui.html}

# 3. Figma: Plugins -> Development -> Import plugin from manifest…
#    выбрать plugin/manifest.json
```

## Аутентификация

Сервер подхватывает `server/.env` (см. `.env.example`):

- **Claude**: `ANTHROPIC_BASE_URL` + `ANTHROPIC_AUTH_TOKEN` (прокси) либо `ANTHROPIC_API_KEY` / рабочий OAuth
  в Claude Code.
- **Devin**: `WINDSURF_API_KEY` либо автоматически из
  `%APPDATA%\devin\credentials.toml` (ставится Devin Desktop).

## Настройки сервера (env / .env)

| Переменная            | По умолчанию                                                      | Описание                               |
| --------------------- | ----------------------------------------------------------------- | -------------------------------------- |
| `PORT`                | `8787`                                                            | порт WebSocket-сервера                 |
| `CLAUDE_ACP_BRIDGE`   | `server/bridges/claude/index.mjs`                                 | путь к Claude ACP-мосту                |
| `DEVIN_CLI`           | автоопределение (Devin Desktop / PATH)                            | путь к `devin.exe`                     |
| `FIGMA_AGENT_WORKDIR` | cwd процесса                                                      | `cwd` для ACP-сессий Claude            |
| `MODELS`              | см. `index.mjs`                                                   | список `id=Лейбл,…`, `devin:*` → Devin |

## Использование

1. Открыть плагин в Figma → выбрать модель → описать дизайн → Enter.
   Модели `devin:*` идут через Devin ACP, остальные — через Claude-мост.
2. Модель возвращает JSON-спеку (схема в `server/prompt.mjs`), плагин строит
   корневой фрейм в центре вьюпорта.
3. Агентные возможности:
    - **Выделение** — выделенные фреймы/группы/тексты сериализуются и уходят
      модели как контекст (чип «выделено: …», крестик — исключить).
    - **`"replace":"<id>"`** — агент сам решает, создать новый фрейм или
      удалить указанную ноду и построить новую на её месте.
    - **`{"inspect":[ids]}`** — агент может запросить PNG-скриншоты нод,
      прежде чем отвечать (до 4 за раз, число раундов не ограничено).
    - **Авторевью** — после сборки фактическое дерево нод уходит модели на
      проверку; при проблемах приходит исправленная спека и фрейм
      пересобирается (число итераций не ограничено, останавливается кнопкой «Стоп»).
4. Следующий запрос отправляется вместе с прошлой спекой — можно итерировать
   («сделай фон тёмным», «добавь секцию цен»). История чата и последняя
   спека сохраняются в `figma.clientStorage` между запусками плагина.

## Схема спеки (кратко)

Корень — `frame` с числовыми `w`/`h`. Типы узлов: `frame` (auto-layout:
`layout`, `gap`, `padding`, `align`, `cross`), `text`, `rect`, `ellipse`,
`line`, `image` (плейсхолдер), `icon` (иконка Lucide по имени — `icon:"search"` — или собственный SVG; эмодзи в дизайне запрещены и вычищаются сервером). Размеры: число px | `"hug"` | `"fill"`.
Цвета: `#RRGGBB` / `#RRGGBBAA`. Полная схема — в `server/prompt.mjs` и
типах `plugin/src/spec.ts`.

## Настройки плагина

Кнопка-шестерёнка в панели ввода открывает настройки:

- **Правила** — свободный текст (до 8000 символов), который добавляется к системному
  промпту в каждом запросе: бренд, стиль, тексты, имена слоёв. Формат ответа они не меняют.
- **Модели** — доступны все модели подключённых провайдеров (Claude, Devin, свои
  ACP-агенты); их списки запрашиваются у провайдеров автоматически. В настройках любую
  модель можно отключить (она пропадёт из списка у поля ввода) и переименовать (в настройках только название и переключатель). Устаревшие и служебные модели скрыты: Fusion, Adaptive, GPT старше 6-го поколения, Claude старше 5-го, SWE кроме второго. Варианты
  одной модели Devin объединены: уровень размышления (Low, Medium, High, XHigh, Max…) и
  Fast выбираются отдельными опциями у поля ввода. Настройки хранятся в
  `figma.clientStorage`.

### Свои ACP-агенты

Команды запуска агентов задаются **только на сервере** — в `server/agents.json`
(пример: `server/agents.example.json`; путь можно переопределить через `AGENTS_FILE`).
Из интерфейса плагина запустить произвольную программу нельзя: иначе любой локальный
клиент WebSocket получил бы выполнение кода на вашей машине.

```json
{
	"agents": {
		"gemini": {
			"label": "Gemini CLI",
			"command": "gemini",
			"args": ["--experimental-acp"],
			"authMethodId": "api-key",
			"apiKeyEnv": "GEMINI_API_KEY"
		}
	}
}
```

После перезапуска сервера агент появляется в списке провайдеров настроек, а его модели
получают id `acp:<имя>:<модель>`. Агент запускается одноразово на запрос (как Devin) в
режиме `ask`; ключ берётся из переменной окружения, указанной в `apiKeyEnv`.
