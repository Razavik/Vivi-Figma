# Specimen
A foundry's material: warm oat paper, near-black ink, razor-hairline Didone heads over a plain sans, square 1px rules and one ink-blue signal. All contrast lives inside the letters, none in colour or depth. Not a cream luxury page, not a bold fashion masthead.

## Palette
- paper #f9f3e8 (page) | paper-2 #f1e8db (well, band) | paper-3 #e4d9ca
- ink #130e0a | ink-2 #2e2722 | muted #665f58 | rule #c5bcb1 | rule-2 #9a9085 (control track)
- accent #144bb7 (ink blue: links, guides, one figure; under 5%) | accent-ink #f9f5ec
- guide #3a6cce at 50% alpha (metric guide hairlines, never a fill)
Balance: oat and ink, one blue; bands paper-2 or one ink band with oat type, never blue.

## Type
- Display: Bodoni Moda regular, hero 80-160, lineHeight 1.02, letterSpacing -2%, sentence case. Keep it large so hairlines stay crisp; under ~28px use a sturdier serif. Italic only in running text.
- Body: Geist 17px, lineHeight 1.55; labels medium a step smaller, muted. Compared figures: Geist Mono, tabular.

## Shape and depth (Figma values)
- Radius 0, no shadow, gradient or texture. Rules 1px #c5bcb1; one 3px double rule heads the one table that matters.
- A well is paper-2 inside a hairline. Photo square in a hairline, caption beneath, no type on it.

## Controls
- Primary: square, fill #130e0a, oat text, Geist medium, 48 tall, padding [14,24].
- Secondary: square, 1px ink stroke. Range: 1px #9a9085 track, square ink thumb. Links: 1px blue underline.

## Range
- Statement with guides: one word at poster size with blue hairlines at cap height, x-height, baseline, each named.
- Waterfall rows: one line falling through sizes, size in mono at left, hairlines between.
- Grid as character set: hairline cells across twelve columns, one lead cell four wide with a glyph at display size.

## Voice
Editorial, hand-set, lightly literary; name the face, size, number.
- Never a heavy display head.
- Never a warm accent or cool paper.
- Never a drawn book or device; set the text itself.
